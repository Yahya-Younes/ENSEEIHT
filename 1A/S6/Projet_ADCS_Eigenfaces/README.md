# Projet ADCS – Eigenfaces (1A S6)

Joint *Analyse de Données* / *Calcul Scientifique* project: face recognition with
eigenfaces, and efficient computation of the dominant eigenvectors needed for it.

| Session | Content |
|---|---|
| `Seance_1` | Eigenfaces: PCA of a face database, projection and reconstruction (`eigenfaces.m`, `projection.m`, `puissance_iteree.m`) |
| `Seance_2` | Eigen-solvers: power iteration and subspace iteration v0–v2 with Rayleigh–Ritz projection, block Gram–Schmidt, quality checks (`subspace_iter_v*.m`, `test_*.m`) |
| `Seance_3` | Recognition of faces (with/without mask) using a Gaussian classifier in eigenface space |

Subjects: `Seance_1/ProjetADCS1.pdf`, `Seance_2/ProjetADCS2.pdf`. Run the scripts from
their own folder in MATLAB.
